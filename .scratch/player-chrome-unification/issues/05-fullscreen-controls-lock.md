# 05: 全屏防误触锁

**What to build:** 横屏握着手机看网课时不会误触。全屏时画面左侧出现一个锁定按钮，锁上以后单击、双击、长按、上下左右滑动都不再改变播放；此时点一下画面只出现"解锁"这一个按钮，其它控件都不冒出来；按返回键是先解锁，而不是直接退出全屏或退出播放页；解锁后控件恢复显示并重新开始自动隐藏计时。竖屏不出现这个按钮，不多占地方。

**Blocked by:** 02（接管全屏）、04（手势层重做）

**Status:** done

- [x] 锁定后单击画面只唤出解锁按钮，顶栏、底栏、进度条、中央播放键均不出现
- [x] 锁定期间双击、长按、竖向滑动、横向滑动均不改变播放状态、进度、音量或亮度
