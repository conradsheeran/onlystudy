# 02: 接管全屏——方向策略、沉浸式系统栏、横屏安全区、返回键分层

**What to build:** 全屏这件事由播放页自己说了算。用户点全屏按钮，横屏视频锁定横屏、竖屏视频保持竖屏放大；系统状态栏和导航栏让开，画面真正铺满；横屏时返回键和右上角按钮不再被刘海/挖孔压住；退出全屏后屏幕回到竖屏，而不是停在横着的状态回到列表页。按手机返回键是一层层退的：全屏时先退出全屏，非全屏才退出播放页，屏幕上的返回箭头走完全相同的路径。整个过程画面不黑屏、不重新缓冲，因为播放器只是被重新排版而不是被重建。

**Blocked by:** 01（控件层落地）

**Status:** done

- [x] 点全屏后，横屏视频锁定横屏；竖屏视频（宽高比 < 1）保持竖屏放大，不被强制转横
- [x] 视频宽高比取不到时按横屏处理
- [x] 全屏时系统状态栏与导航栏隐藏（沉浸式），退出全屏后恢复
- [x] 退出全屏后屏幕方向恢复为竖屏，而不是解锁成任意方向
