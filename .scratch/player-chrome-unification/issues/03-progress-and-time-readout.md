# 03: 进度与时间信息增强

**What to build:** 用户随时知道自己看到哪了。控件可见时显示"当前位置 / 总时长"，秒数跳动时数字宽度不抖动、不把旁边的按钮挤来挤去；控件自动隐藏后，屏幕最底部仍保留一条很细的进度条，不用点一下就能看出进度；进度条上能看出已缓冲到哪里，网络卡的时候心里有数；拖动进度条时播放头不会和手指打架往回跳；加载中有明确指示；播放失败时看到的是和应用其它页面一样的错误视图，并且能一键重试，而不是一行白字。

**Blocked by:** 01（控件层落地）
