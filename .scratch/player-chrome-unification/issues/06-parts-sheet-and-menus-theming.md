# 06: 分集列表与弹出菜单归一到应用主题

**What to build:** 播放器里弹出来的东西看起来终于像同一个 App。竖屏时分集列表从底部弹出，能一直滚到最后一集、不被系统手势条或刘海遮住、带拖拽手柄；横屏全屏时它改从右侧滑出，占大约半屏宽、整屏高，不再糊住整个画面。分集列表、倍速菜单、清晰度菜单的底色、文字与选中态全部取自应用主题，播放页里那块突兀的深灰消失。

**Blocked by:** 02（接管全屏）

**Status:** done

- [x] 竖屏分集列表从底部弹出，可滚动到最后一集，不被系统手势条/刘海遮挡，带拖拽手柄
- [x] 横屏（全屏）分集列表从右侧滑出，约占半屏宽、整屏高
- [x] 分集列表的背景、标题、条目文字、选中态取自主题令牌；选中项使用强调色，次要文字使用次级前景色

- [x] 既有行为不回归：从分集列表切换分集、从菜单切换倍速与清晰度、当前项高亮与时长显示
